# 📱 Menu Ứng Dụng Android - Bài Tập Thực Hành

## 🎯 Giới thiệu
Ứng dụng Android với giao diện menu đẹp gồm 4 chức năng chính:
- **Calculator** (Máy tính)
- **Weather** (Thời tiết)  
- **Gallery** (Thư viện ảnh)
- **Task Manager** (Quản lý công việc)

## 📲 Hướng dẫn cài đặt

1. Tải file **app-menu-debug.apk** về điện thoại Android
2. Vào **Settings** → **Security** → Bật "**Install from Unknown Sources**"
3. Mở file APK và nhấn **Install**
4. Mở app và sử dụng! 🎉

## 🎨 Tính năng

### Menu Screen
Giao diện menu với 4 card gradient đẹp mắt:
- ✅ Calculator (Máy tính) - Gradient xanh dương
- ✅ Weather (Thời tiết) - Gradient cam
- ✅ Gallery (Thư viện ảnh) - Gradient tím
- ✅ Task Manager (Quản lý công việc) - Gradient xanh lá

### Calculator Activity
- Các phép tính: +, -, ×, ÷, √, x², %
- Hỗ trợ số thập phân
- Lịch sử tính toán
- Clear và Delete

### Weather Activity
- Chọn thành phố
- Hiển thị nhiệt độ, độ ẩm, tốc độ gió
- Giao diện gradient đẹp

### Gallery Activity
- Grid view 3 cột
- Slideshow tự động
- Navigation Previous/Next

### Task Manager Activity
- Thêm/xóa task
- Đánh dấu hoàn thành
- Lưu trữ với SharedPreferences
